# MongoDB-Basics-Assignment

Completed the MongoDB Basics assignment using `mongosh` on a local `company` database and `employees` collection.

## Files

- `mongodb-basic-assignment.js` — MongoDB commands for Tasks 1–6:
  - **Task 1:** Database setup and inserting the initial 5 employee documents
  - **Task 2:** Read queries with filters, projections, sorting, limiting, dot notation and `$in`
  - **Task 3:** Updates using `$inc`, `$set` and `$addToSet`
  - **Task 4:** Inserting and deleting a temporary document (`EMP999`) with `deleteOne()`
  - **Task 5:** Inspecting indexes with `getIndexes()` and creating an ascending index on `department`
  - **Task 6:** Aggregation pipelines using `$match`, `$group`, `$project`, `$sort` and `$limit`
- `answers.md` — Answers and short explanations for the 10 MongoDB Fundamentals MCQs (Task 7).
